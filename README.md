# DontPayFull Homebrew tap

```bash
brew install dontpayfull/tap/ainotate
```

| Formula | What it is |
|---|---|
| [ainotate](https://github.com/dontpayfull/AInotate) | Annotated screenshots for AI agents: numbered steps, Skitch-style arrows, boxes, labels and solid redaction. CLI, MCP server and agent skill. |

The formula installs the release from PyPI into its own virtualenv. A daily
workflow moves it to each new release.
